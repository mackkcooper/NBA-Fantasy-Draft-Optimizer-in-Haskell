# NBA Fantasy Draft Optimizer

## Project

This project was created to assist with Fantasy Basketball Drafting so that you can compare any given player with an existing roster and optimize for that roster.

## Build

This project requires GHCI and Cabal in order to run.

`cabal update` to update cabal before running.

`cabal install` to download the necessary packages

`cabal new-repl` in order to start the interpreter and call the functions.
